Private companion setup
This companion is intentionally private. Postal AutoClip is not planning to submit it to RuneLite Plugin Hub during the private beta. Invited testers use the bundled private development-client package only after AutoClip itself is already installed and usable. AutoClip never automates gameplay and never needs your Jagex password.

For Jagex Accounts, RuneLite's official development-client flow may require temporarily enabling --insecure-write-credentials so RuneLite writes launcher credentials for a development client. Those credentials can log into the account and must never be shared. AutoClip does not automate that setting, upload that credential file, or copy it into AutoClip storage. Follow RuneLite's official development instructions explicitly, remove the argument when testing is complete, and delete the temporary credential file when it is no longer needed.

The companion sends only local event metadata to 127.0.0.1:8787. Keep this page open during initial validation; CONNECTED plus live events confirms the private bridge is working.
